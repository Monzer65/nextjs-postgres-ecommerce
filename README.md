# Shopsy E-Commerce Platform

This is **SHOPSY** an **E-Commerce Platform**, designed to provide a seamless experience for both customers and administrators. This project includes a full-control admin panel, allowing you to manage products, orders, users, and more with ease.

## Features

### Customer-Facing Features

- **Product Catalog**: Browse through a wide range of products with detailed descriptions, images, and pricing.
- **Search & Filter**: Easily search for products and filter by category, price range, ratings, and more.
- **User Accounts**: Create and manage user accounts, including order history, wishlists, and saved payment methods.
- **Shopping Cart**: Add products to your cart, update quantities, and proceed to checkout.
- **Secure Checkout**: Multiple payment options, including credit card, PayPal, and more, with secure transaction processing.
- **Order Tracking**: Track your orders in real-time with status updates and shipping information.
- **Product Reviews & Ratings**: Share your feedback and read reviews from other customers.

### Admin Panel Features

- **Dashboard**: Get an overview of your store's performance, including sales, orders, and user activity.
- **Product Management**: Add, edit, or remove products, including images, descriptions, pricing, and inventory levels.
- **Order Management**: View and manage orders, update order statuses, and handle returns or refunds.
- **User Management**: Manage customer accounts, including roles, permissions, and activity logs.
- **Category Management**: Organize products into categories and subcategories for easy navigation.
- **Promotions & Discounts**: Create and manage promotional campaigns, discount codes, and special offers.
- **Analytics & Reports**: Generate detailed reports on sales, customer behavior, and product performance.
- **Content Management**: Manage static content such as blog posts, FAQs, and terms of service.
- **Settings**: Configure store settings, including payment gateways, shipping options, and tax rates.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript, React.js, Next.js
- **Backend**: Next.js
- **Database**: PostgreSql on Neon.tech
- **Authentication**: Session-based Auth
- **Payment Gateway**: Stripe, PayPal
- **Admin Panel**: 100% custom-made admin panel
- **Deployment**: Vercel

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Monzer65/shopsy.git
   cd shopsy
   npm i
   ```
